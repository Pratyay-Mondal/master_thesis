## 1. The Generative Language Model Sampling Paradigm

Unlike digital media containers that encapsulate discrete pixel matrices, large language models (LLMs) emit text autoregressively as sequences of discrete vocabulary tokens. At each generation step $t$, given preceding context tokens $x_{<t} = (x_1, \ldots, x_{t-1})$ and a fixed vocabulary $V$, the model computes a logit vector $\ell_t \in \mathbb{R}^{|V|}$. A next-token probability distribution is obtained via the softmax activation function:

$$p_{\text{LM}}(v \mid x_{\lt t}) = \frac{\exp(\ell_t(v))}{\sum_{v' \in V} \exp(\ell_t(v'))}, \quad \forall v \in V$$

Under standard temperature-scaled nucleus (top-$p$) sampling, token $x_t$ is sampled stochastically from $p_{\text{LM}}$. 

**The Watermarking Hinge:** Generative statistical watermarking does not retrain model weights, append metadata tags, or inject zero-width steganographic Unicode characters. Instead, it subtly modulates **which plausible tokens are sampled** during the decoding loop using a secret pseudo-random function. Detection later assesses whether the sequence exhibits statistical deviations from human language distributions.

## 2. The Kirchenbauer Green-List Framework

The foundational statistical text watermarking architecture was formulated by Kirchenbauer et al. (ICML 2023). It establishes a three-stage mathematical pipeline: context hashing, vocabulary partitioning, and logit biasing.

```
Kirchenbauer Generative Sampling Loop:
┌─────────────────┐       ┌────────────────────────┐       ┌────────────────────────┐
│ Context Tokens  │──────►│ Keyed PRF (HMAC-SHA256)│──────►│ Random Partition       │
│ x_{t-h:t-1}     │       │ Seed: r_t = PRF_k(...) │       │ V = G_t ∪ R_t          │
└─────────────────┘       └────────────────────────┘       └────────────────────────┘
                                                                        │
                                                                        ▼
┌─────────────────┐       ┌────────────────────────┐       ┌────────────────────────┐
│ Sampled Token   │◄──────│ Softmax Sampling       │◄──────│ Logit Modulation       │
│ x_t ~ p̂(v)      │       │ p̂(v) = softmax(ℓ̂_t)   │       │ ℓ̂_t(v) = ℓ_t(v) + δ    │
└─────────────────┘       └────────────────────────┘       └────────────────────────┘
```

### 2.1 Context-Keyed Pseudo-Random Partitioning
At generation step $t$, the generator inspects a sliding window of the preceding $h$ tokens (the $h$-gram context). A pseudo-random seed $r_t$ is generated by evaluating a keyed Hash-based Message Authentication Code (HMAC-SHA256) over the context:

$$r_t = \text{PRF}_k(x_{t-h}, \ldots, x_{t-1})$$

The seed $r_t$ initializes a deterministic pseudo-random number generator that randomly partitions the entire vocabulary $V$ into a **green list** $G_t$ and a **red list** $R_t$:

$$V = G_t \cup R_t, \quad G_t \cap R_t = \emptyset, \quad |G_t| = \gamma |V|$$

where $\gamma \in (0, 1)$ denotes the green-list fraction (standard default: $\gamma = 0.5$).

### 2.2 Soft Logit Perturbation
To bias token selection toward the green list without corrupting semantic coherence, a positive logit bias $\delta > 0$ is added to all green-list tokens before applying the softmax operator:

$$\hat{\ell}_t(v) = \begin{cases} \ell_t(v) + \delta & \text{if } v \in G_t \\ \ell_t(v) & \text{if } v \in R_t \end{cases}$$

$$\hat{p}(v) = \frac{\exp(\hat{\ell}_t(v))}{\sum_{v' \in V} \exp(\hat{\ell}_t(v'))}$$

Under high-entropy completions (where multiple synonyms are plausible), the $+\delta$ bias comfortably nudges the sampler to select a green token. Under low-entropy completions (where a single token dominates the distribution, such as dates or syntax), the raw logit gap exceeds $\delta$, preserving the dominant token and avoiding catastrophic hallucinations.

## 3. Zero-Shot Detection and Hypothesis Testing

A primary operational advantage of statistical text watermarking is that **detection is zero-shot**: it requires neither the original prompt, nor model weights, nor access to the language model itself. The detector requires only:
1. The candidate text string $x = (x_1, \ldots, x_T)$.
2. The secret key $k$.
3. The algorithmic parameters $(\gamma, h)$.

### 3.1 The Null and Alternative Hypotheses
The detection protocol formulates a classical hypothesis test:
- **Null Hypothesis ($H_0$):** The text span was generated without knowledge of key $k$ (i.e., human-authored text, or text generated by an unwatermarked/differently-keyed model).
- **Alternative Hypothesis ($H_1$):** The text was generated by a language model using key $k$ with green-list bias $\delta > 0$.

### 3.2 Test Statistic Derivation
Under $H_0$, assuming the PRF outputs independent pseudo-random hashes, each scored token $x_t$ falls into its dynamically generated green list $G_t$ with probability $\gamma$ independently. For a text containing $T$ scored tokens ($T = n - h$), the total green token count $|s|_G = \sum_{t=h+1}^n \mathbb{I}(x_t \in G_t)$ follows a Binomial distribution:

$$|s|_G \sim \text{Binomial}(T, \gamma)$$

$$\mathbb{E}[|s|_G \mid H_0] = \gamma T, \quad \text{Var}(|s|_G \mid H_0) = \gamma(1 - \gamma)T$$

For $T \ge 30$, by the Central Limit Theorem, the distribution of $|s|_G$ converges to a Gaussian distribution $\mathcal{N}(\gamma T, \gamma(1-\gamma)T)$. We construct the standard one-proportion $z$-score statistic:

$$z = \frac{|s|_G - \gamma T}{\sqrt{\gamma(1 - \gamma)T}}$$

For standard symmetric partitioning ($\gamma = 0.5$), this simplifies to:

$$z = \frac{2 |s|_G - T}{\sqrt{T}}$$

The one-sided $p$-value represents the probability of observing at least $|s|_G$ green tokens under $H_0$:

$$p = 1 - \Phi(z) = \frac{1}{\sqrt{2\pi}} \int_z^\infty \exp\left(-\frac{u^2}{2}\right) du$$

### 3.3 Operating Thresholds & Length Gating
In the empirical harness of this thesis, the detection decision rule is parameterized at:

$$\text{Decision: Reject } H_0 \iff z > 3.00 \quad (p < 1.35 \times 10^{-3})$$

Industrial deployments (e.g., Anthropic, Google) enforce even stricter thresholds ($z > 4.0$ or $z > 5.0$, corresponding to $p < 3 \times 10^{-5}$) to prevent false-positive accusations of AI generation against human creators.

Because the expected $z$-score scales with the square root of sequence length:

$$\mathbb{E}[z \mid H_1] \approx \left(\frac{\mathbb{E}[\text{green rate}] - \gamma}{\sqrt{\gamma(1-\gamma)}}\right) \sqrt{T}$$

Detection confidence is **strictly length-gated**. If $T$ is small (e.g., an Instagram caption with $T = 20$ tokens), even a high green-token rate ($\approx 75\%$) yields:

$$z \approx \frac{2(15) - 20}{\sqrt{20}} = \frac{10}{4.47} \approx 2.24 < 3.00 \implies \text{Inconclusive (Miss)}$$

## 4. Industrial Generalization: DeepMind SynthID-Text & Anthropic Claude

While Kirchenbauer’s green-list system provides an inspectable foundational model, production deployments on Google Gemini and Anthropic Claude utilize **tournament sampling** formulations designed to preserve text quality and integrate with speculative decoding clusters.

```
SynthID-Text Multi-Layer Tournament Sampling:
Candidate Tokens (M = 2^m sampled from p_LM)
┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐
│ cand0 │ │ cand1 │ │ cand2 │ │ cand3 │
└───┬───┘ └───┬───┘ └───┬───┘ └───┬───┘
    │   g_1   │         │   g_1   │
    └───┬─────┘         └───┬─────┘
        ▼                   ▼
    ┌───────┐           ┌───────┐
    │ win_A │           │ win_B │
    └───┬───┘           └───┬───┘
        │        g_2        │
        └─────────┬─────────┘
                  ▼
          ┌───────────────┐
          │ Output: x_t   │ (Final Token)
          └───────────────┘
```

### 4.1 Tournament Sampling Mechanics (Dathathri et al., Nature 2024)
Rather than explicitly perturbing raw logits with $+\delta$, DeepMind's SynthID-Text operates as follows:
1. **Candidate Pool Sampling:** At step $t$, draw $M = 2^m$ candidate tokens from the unperturbed distribution $p_{\text{LM}}$.
2. **Pseudorandom $g$-Functions:** Define $m$ independent binary hash functions $g_\ell(v, r_t) \in \{0, 1\}$ parameterized by a secret key vector `keys` and sliding context $r_t$.
3. **Tournament Hierarchy:** The $M$ candidates are paired. At tournament layer $\ell$, pairs compete; the candidate with the higher $g_\ell$ value advances. The single token surviving all $m$ layers is emitted as $x_t$.
4. **Scoring Function:** Detection does not compute green-list fractions; it evaluates the mean $g$-score across all layers and tokens:
   $$\text{Score}(x) = \frac{1}{m T} \sum_{t=1}^T \sum_{\ell=1}^m g_\ell(x_t, r_t)$$
   Under $H_0$, $\mathbb{E}[\text{Score}] = 0.5$. Under $H_1$, the score is significantly shifted toward $1.0$.

### 4.2 Distortion-Free vs. Distortionary Modes
SynthID-Text provides two operational configurations:
- **Distortionary Mode:** Maximizes detection power by aggressively pruning candidates; introduces minor shifts in text perplexity.
- **Non-Distortionary Mode:** Mathematically guarantees that the marginal distribution of sampled tokens matches $p_{\text{LM}}$ exactly ($\mathbb{E}[\hat{p}(v)] = p_{\text{LM}}(v)$). This ensures that watermarking has **zero impact on model reasoning or perplexity benchmarks**, satisfying enterprise SLAs.

### 4.3 Anthropic Claude Watermark Architecture
In August 2026, Anthropic published technical documentation confirming their implementation of a SynthID-Text variant to comply with EU AI Act Article 50:
1. **Zero Extra Tokens:** The watermark is embedded entirely in the sampling dynamics; no prefix, suffix, or special formatting tokens are appended.
2. **Identity-Free Design:** The secret key is tied to the model release (e.g., Claude 3.5 Sonnet), not individual user accounts, prompts, or conversation IDs. It complies with GDPR Article 5(1)(c) data minimisation by embedding zero personal data.
3. **Provider Key Dependency:** Detection requires Anthropic's private key. Third-party auditors cannot independently verify watermarks without querying an authenticated Anthropic verification API.

## 5. Information-Theoretic Bounds & Empirical Entropy Constraints

The capacity of any autoregressive watermarking scheme to embed detectable signal without semantic distortion is strictly bounded by the **conditional Shannon entropy** of the language model's predictive distribution:

$$H(X_t \mid X_{\lt t}) = -\sum_{v \in V} p(v \mid X_{\lt t}) \log_2 p(v \mid X_{\lt t})$$

### 5.1 The Entropy Gating Mechanism
- **High-Entropy Positions ($H \ge 2.5\text{ bits}$):** The model assigns probability mass across multiple acceptable continuations (e.g., descriptive prose, adjectives, connective adverbs). The watermarking sampler can freely steer choice toward green tokens with zero semantic penalty.
- **Low-Entropy Positions ($H < 1.0\text{ bit}$):** The model's distribution is peaked around a single deterministic continuation (e.g., syntactic code tokens `def`, `return`, structured dates, or named entities like *"European Union"*). Applying logit bias $\delta$ either fails to alter the argmax, or forces a syntactically illegal or factually hallucinated token.

### 5.3 The Two Fundamental Failure Modes in Social Feeds
1. **The Syntactic Trap (Code & Structured Data):** In code snippets shared on social platforms, average entropy collapses to $1.98\text{ bits/token}$, with **75.0% of tokens completely non-nudgeable**. Watermarking is statistically inoperative on programming languages and structured tables.
2. **The Micro-Span Power Collapse (Social Media Captions):** While captions exhibit moderate vocabulary entropy ($4.29\text{ bits/token}$), their total length is critically constrained ($T = 22\text{ tokens}$). Because detection power scales with $\sqrt{T}$, micro-spans on Instagram, Threads, and WhatsApp operate in a **statistical dead zone** where no watermark can be detected with regulatory confidence.

## 6. Synthesis: Technical Reality vs. Article 50 Compliance

1. **Survival Advantage Over C2PA:** Unlike C2PA image metadata, statistical text watermarks survive verbatim copy-pasting, social media CDN caching, and WhatsApp end-to-end encrypted messaging without degradation.
2. **The Inoperable Micro-Span Reality:** Because text watermarks are length-gated, they cannot fulfill Article 50(2) on short captions, titles, or status updates.
3. **The Closed Ecosystem Dilemma:** Because SynthID-Text detection requires private provider keys, independent verification is impossible without platform cooperation, requiring client-side extensions to route queries through authenticated provider gateways.
